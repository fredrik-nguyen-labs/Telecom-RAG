Transparency

Privacy notice

This is a public telecom research demonstration. This page describes what the application does with data when you use it. Last updated: 17 October 2026.

Please don't enter personal, confidential or proprietary network information.

The demo is public, and questions are processed by third-party hosting and AI providers.

What you submit

When you send a question, your question, the selected measurement values (if any), and a bounded recent conversation history are transmitted over HTTPS to the Telecom RAG API on Render. The API may send relevant text, retrieval queries and technical context to Cloudflare Workers AI to generate an answer. Retrieved reference documents and public measurement data are held in Supabase.

What the application stores

Chat messages are held in your open page's memory for follow-up questions. The application does not deliberately save your conversations to its Supabase database, put them in persistent browser storage, or create user accounts. Refreshing or closing the page clears that in-memory conversation. Reference documents and public KPI observations are persistently stored as part of the demo's dataset.

Hosting logs and third parties

Render and other network infrastructure may process standard technical logs, such as IP addresses, request paths, response status and timestamps, for service delivery, reliability and security. Cloudflare Workers AI processes model inputs needed to answer your questions. Supabase processes reference-data retrieval. Each provider has its own processing and retention practices; this site cannot promise that all third-party logs are immediately deleted.

Cookies, analytics and advertising

The application does not implement advertising, a tracking pixel, or its own analytics cookies. Infrastructure providers may still use strictly operational data or cookies according to their own policies. Following links to external references takes you to independent websites with their own practices.

Security

The site uses HTTPS, limited browser-to-API origins, restricted runtime credentials and bounded requests. No internet service can guarantee absolute security. Do not submit sensitive information to this research demo.

Questions or privacy requests

For questions about the application or requests concerning information sent to it, contact the maintainer using an appropriate private contact method listed on the GitHub profile. Do not place personal data or credentials in public issues. Where a request concerns a third-party provider's records, its own privacy policy may also apply.

Also see the usage terms and limitations.
